### Pourquoi un escape game

Les élèves ont déjà vu ces notions trois fois : le 2 novembre (le clic au ralenti), le 20 novembre (la synthèse), et sur la fiche de révision. Une quatrième explication ne passerait pas. Ici, **le professeur n'explique presque rien** : chaque énigme est un problème concret, et la méthode est dans le carnet du détective. Les élèves réutilisent ce qu'ils savent, ce qui est exactement ce qu'il faut pour réviser. Les schémas et les exemples sont **tous nouveaux** : rien ne ressemble à une redite.

### Lancer le jeu (les 5 premières minutes)

1. Faire entrer les élèves **directement en équipes** (îlots déjà formés, noms au tableau). Ne pas commencer par « aujourd'hui on révise ».
2. Projeter le message de la MDL, le lire à voix haute, avec un peu de mise en scène : « Je l'ai reçu hier soir à 21 h 47. »
3. Poser la boîte et son cadenas sur le bureau, si vous en avez une. Même sans bonbons dedans, l'objet suffit à créer l'envie.
4. Les règles en une minute, puis l'annonce : « La note de cette fiche peut remplacer celle du 20 novembre. »

### Le plan de bataille

| Moment | Ce que je fais |
| :--- | :--- |
| **La veille** | J'écris le nom de chaque élève sur sa fiche, et je forme les 6 équipes (niveaux mélangés, bavards séparés). |
| **Avant qu'ils entrent** | Îlots formés, fiches posées : chacun cherche sa fiche, et son équipe. Le tableau des scores est déjà tracé. |
| **Minute 1 à 5** | « Lancer le jeu » ci-dessus : le message de la MDL, le cadenas, les règles. Rien d'autre. |
| **Pendant les énigmes** | Minuteur projeté. Je passe dans chaque îlot : **chacun écrit** sur sa fiche, pas seulement le secrétaire. |
| **Entre deux énigmes** | Correction express d'une minute, score au tableau, une anecdote si l'ambiance retombe. |
| **Fin d'heure** | Ouverture du cadenas, trace écrite, puis je suis **à la porte** : on sort en me donnant sa fiche. |

L'interrogation reste au **4 décembre** : cette heure est la dernière révision. Dire en sortant : « Ce que vous avez trouvé aujourd'hui, c'est ce qui tombe vendredi prochain. »

### Tenir le rythme

- **Le minuteur est votre allié** : appuyer sur T dès le début de chaque énigme ; à la fin, « 3, 2, 1, chiffres en l'air ! ».
- Le tableau des scores au tableau, mis à jour **à chaque énigme** : c'est ce qui tient les équipes.
- Passer dans les îlots et vérifier que **chacun écrit**, pas seulement le secrétaire de l'équipe. Une phrase utile : « Je ramasse une fiche au hasard dans chaque équipe à la fin. »
- Si une énigme traîne, donner l'indice à toute la classe gratuitement et passer à la suite : les énigmes sont indépendantes.

### Le fil rouge : tout se tient

Le moment fort est la correction de l'énigme 3 : le lien `tarifs.html` mal écrit dans la page explique les deux erreurs 404 du journal (énigme 2). Le dire à voix haute : « Vous voyez ? Un visiteur clique, le navigateur demande `tarifs.html`, le serveur ne trouve pas, 404. Le problème n'était pas sur le serveur, il était dans le code HTML. » C'est le voyage d'un clic, mais ce sont les élèves qui l'ont reconstitué.

| Quand | Anecdote |
| :--- | :--- |
| Après l'énigme 1 | **Les arnaques par SMS** utilisent exactement le piège du lien 2 : un vrai nom au début, le vrai serveur à la fin. L'Assurance maladie, La Poste ou les impôts sont souvent imités. Exemple inventé à montrer : `https://www.ameli-remboursement-info.com` n'est pas le site de l'Assurance maladie. |

Bonne occasion de parler de vérification des sources. Et le **code 418 « I'm a teapot »** (je suis une théière) est un vrai poisson d'avril de 1998. |
| Après l'énigme 3 | **Le tout premier site web existe toujours** : `info.cern.ch`. Du texte et des liens, aucune image, aucun style : le CSS n'est arrivé que plus tard. |
| Après l'énigme 4 | **La première photo publiée sur le Web** (1992) est celle des « Horribles Cernettes », un groupe de musique parodique formé par des employées du CERN. |
| Après l'énigme 5 | Les **cookies** ont été inventés en 1994 par Lou Montulli, chez Netscape, pour qu'un site de vente se souvienne du panier : exactement le cookie `panier` de la MDL. |

### Pourquoi c'est utile pour eux

- **Se protéger** : savoir lire le serveur d'un lien, c'est éviter la plupart des arnaques par SMS ou par mail.
- **Comprendre les messages d'erreur** : 404, « connexion non sécurisée » : ils sauront ce qui a cassé.
- **Avoir le droit** : une image trouvée sur Internet n'est pas libre. La licence le dit, et c'est utile dès leurs exposés.
- **L'interrogation du 4 décembre** : chaque énigme en est une partie.

### Ce qui bloque souvent, et comment débloquer

| Blocage | Ce que je dis ou je fais |
| :--- | :--- |
| « Le lien 2 commence par le bon nom, il est bon ! » | « Où s'arrête le serveur ? Mettez votre doigt sur le premier `/`. Lisez ce qui est juste avant. » |
| « Le lien 1 a le bon serveur, donc il est bon » | « Le bon site, oui. Mais regardez le protocole : vous donneriez votre commande sur une carte postale ? » |
| Le journal fait peur | « Ne lisez que la dernière colonne. » Puis une ligne à voix haute : « À 19 h 02, quelqu'un a demandé la page de commande, et le serveur a dit OK. » |
| L'élève recopie les balises dans le dessin | « Les balises, c'est la recette ; vous ne mangez pas la recette, vous mangez le plat. » |
| Licences : l'élève ne sait plus les lettres | Renvoyer au carnet du détective : il est fait pour ça. |
| Cookie tiers / cookie du site | « Qui a déposé ce cookie ? Est-ce le site sur lequel je suis ? » |
| Une équipe ne fait rien | Lui confier le rôle de « vérificateur » d'une autre équipe pour l'énigme suivante, ou lui donner un joker gratuit pour la relancer. |

### Si la classe décroche ou si le temps manque

Supprimer l'énigme 4 (licences) en classe et la donner à finir à la maison sur l'ENT : le chiffre du cadenas est alors donné (9). Ne jamais supprimer l'énigme 3 : c'est elle qui relie tout.
